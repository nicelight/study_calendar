# Frontend «Тихий фокус»: интеграционная проверка

Основание: оператор разрешил реализацию предложенного направления с максимум
тремя Luna xhigh и проверкой главным агентом. Все три воркера запущены с
`gpt-5.6-luna`, `reasoning_effort: xhigh` и непересекающимися исходными файлами.

## Разделение работы

- Boyle: публичный и авторизованный календарь; затем browser QA.
- Confucius: экран урока; затем read-only review файлов главного агента.
- Parfit: четыре Admin-страницы.
- Главный агент: общая CSS-тема, layout/navigation, login/invite, Home/Classes,
  Profile, Statistics, вход в класс; интеграция, проверки, исправления и документация.

Начальный dirty worktree сохранён, включая исправления homework aria-label,
finance hydration и E2E из предыдущей работы. Серверные модули, формы запросов,
права доступа и финансовые правила не менялись.

## Проверка и корректировки

- Проверены диффы всех групп. Убраны глобальные палитры страниц, локальные стили
  используют общую тему `src/lib/workspace-theme.css`.
- После первого review уменьшены завышенные заголовки и отступы; добавлены
  различимые границы полей. Динамические invalid-селекторы корректно ограничены
  областью страницы, не подавляя диагностику Svelte.
- Source-based тест навигации теперь допускает дополнительные атрибуты
  (`aria-current`), по-прежнему проверяя точные четыре маршрута.
- Возвращены простая публичная ссылка «Вход» и точная подпись формата класса.
- Smoke-проверка сохранения материала ограничена `.material`, чтобы не
  захватывать одноимённый текст в textarea редактора.
- Главный агент просмотрел desktop public/lesson и mobile calendar/finance
  screenshots. Найден mobile Finance overflow из-за min-content размера grid;
  добавлены `min-width: 0` и вертикальное расположение заголовков на телефоне.
- Повторные finance screenshots подтверждают устранение растягивания страницы.
- Независимый review Confucius выявил отсутствующую цель `aria-controls` закрытого
  меню, отсутствие Space у сортировки и слабый контраст полей. Исправлены все три:
  условный атрибут, обработчик Space с сохранением нативного Enter, граница
  `#7C9588` с вычисленным контрастом 3,23:1 на белом. В существующий statistics
  Playwright-сценарий добавлены проверки Space/Enter и порядка строк; он прошёл.

## Автоматические результаты

- `npm run test`: 79 файлов, 271 тест пройдены после корректировки разметки.
- `npm run check`: 0 errors, 0 warnings после исправления динамических CSS-селекторов.
- `npm run build`: успешно.
- Все 10 disposable Playwright feature specs пройдены по одному через
  `node scripts/run-disposable-e2e.mjs --database tmp/<name>.db --spec e2e/<spec>.spec.ts`.
  Финансовые specs повторно пройдены после CSS-реализации Finance.
- Два real-database specs запускаются на отдельной SQLite backup-копии
  `tmp/design-real-smoke.db`, порт 5176; исходная `study-calendar.db` не изменяется.
- Последний стабильный запуск real specs: 2/2 passed, включая mobile free-day
  navigation. Перед ним один прогон не зарегистрировал клик во время активных
  изменений исходников; утверждение теста сохранено, повторный прогон успешен.
- Финальная сверка всех пользовательских SQLite-таблиц с исходной review-копией
  (за исключением искусственных review-сессий) не нашла различий в строках.
  Метаданные файла изменились во время проверок; неизменность mtime не заявляется.
- Первый повторный journal-прогон имел `ERR_ABORTED` при параллельной сборке;
  после завершения сборки тот же сценарий прошёл. Причина не доказана как
  дефект приложения; final browser evidence получается при стабильных исходниках.

## Browser evidence

Скрипт [qa.mjs](qa.mjs) работает на отдельном review-сервере 5175 с копией БД.
Изображения в этой папке содержат локальные данные и предназначены для просмотра
оператором; не для публикации. Performance metrics короткого idle-интервала

## Результат browser review

Boyle проверил 1440×1000 и 390×844: public/login, Student/Parent calendar и
lesson, Admin Home/Profile/Statistics/center/Finance. В итоговой проверке
`pageerror` и `console.error` отсутствуют. Finance: ширина документа 390/390,
таблица прокручивается внутри собственного контейнера (319 → 1042 px).
Mobile Admin также без document overflow. Space/Enter меняют `aria-sort`.
Повторная проверка free-day click переводит на URL с `date`.

В коротком idle-пробнике TaskDuration delta составила 0.000156 s для Admin
и 0.000177 s для Finance; при reduced motion runningAnimations=0.
Это локальные наблюдения Chrome dev-сервера, не сравнительный benchmark CPU.

Главный агент дополнительно просмотрел обновлённые Finance full-page/viewport,
mobile Statistics и desktop Lesson. По последнему замечанию QA уменьшен
горизонтальный padding мобильной calendar day с .8rem до .5rem: это увеличивает
доступную ширину ссылки и подписи внутри неизменных elastic tracks.
Проба более плотной недели показала, что одного padding недостаточно. Для
мобильных ячеек добавлена минимальная ширина 5.5rem; горизонтальный scroll недели
сохраняет доступность всех дат без сжатия зоны нажатия.
Финальная проверка при 390×844: минимальная ссылка 70×46.72 px, подпись
«Свободно» целиком; документ 390/390 без overflow, ширина внутреннего scroll
недели 324 → 661 px; пересечений ячеек 0. Снимок:
[mobile calendar final](mobile-390x844-calendar-admin-final-2.png).

Финальные build/check: успешно, 0 errors / 0 warnings; Vitest 271/271.
Итог существующих Playwright-сценариев: 10 disposable и 2 smoke успешны;
отдельная проверка Space/Enter также успешна.

Все три воркера закрыты. Review-сервер остановлен; временные backup-БД и их
точные SQLite sidecars удалены. Они воспроизводимы из рабочей БД; screenshots
и скрипт проверки сохранены. Коммиты и публикация не выполнялись.
