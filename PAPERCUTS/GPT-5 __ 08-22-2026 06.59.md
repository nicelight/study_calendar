# Papercut

- Vitest's project config only includes `tests/**/*.test.ts`, so an evidence probe under `.tasks/` reported “No test files found” until it was run with a task-local Vitest config.
- The first inline source-boundary probe treated type-only `.server` imports in Svelte files as runtime server access; the check was narrowed to actual `$lib/server` imports, matching the existing route contract.
- The first version of the semantic route probe did not replace the production composition-root singleton, so its positive fixture used the wrong database; the probe now injects its in-memory root before exercising the actual route loaders.
