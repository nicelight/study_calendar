# Papercut — required full test gate mutates ignored real database

- During TASK-101 execution, the disposable Playwright gate used only
  `tmp/ft-006-payment-markers.db`; immediately before and after its final
  successful run, `study-calendar.db` had SHA-256
  `5421ad92b1354e40909df02587e75ef13e1afc8bf8db81e88adecbb8389c8b5c` and
  the disposable database/sidecars were cleaned.
- After the required full `npm run test` gate, `study-calendar.db` had mtime
  `2026-09-05 02:07:15 +0500` and SHA-256
  `2b94cf997f2c8df69acd45b4e3767d0a269e178d3f478aec9400aee44b0c9937`.
- The file is ignored by `.gitignore` (`*.db`), so the mutation is invisible to
  `git status`. No task implementation path intentionally opened or wrote this
  database, and it was not restored or deleted because its prior contents are
  not reconstructible from the current worktree.
- Impact: the project-level `npm run test` gate is not proven to be isolated
  from real runtime data; future test isolation should identify the test using
  the default `DATABASE_URL`/database filename and prevent this side effect.
