# Papercuts

- Several read-only shell invocations emitted `Failed to create stream fd:
  Operation not permitted` before otherwise completing normally; the message
  added noisy output but did not change command results.
- A read-only final-state scan embedded a Markdown backtick inside a shell
  double-quoted argument, so Bash treated it as command substitution and
  stopped with an unmatched-backtick syntax error; rerunning with a plain
  pattern avoided the quoting hazard.
