Puppeteer Core's Locator API does not support locator nesting (`scheduleForm.locator(...)`), unlike Playwright. Use a single page-level selector for nested elements in browser QA scripts.

Puppeteer Core Locator also lacks Playwright collection APIs such as `count()` and `filter()`. Prefer ordinary CSS selectors or DOM inspection for collection queries.

The local `lessons` table does not use the guessed `date`/`starts_at`/`ends_at` column names; inspect `PRAGMA table_info` before a read-only evidence query.
