# Papercuts

- Первая shell-команда secrets-scan завершилась syntax error из-за смешанных кавычек в одном regex. Надёжнее передавать секретные сигнатуры в `rg` отдельными `-e` без regex с вложенными quote-символами.
- `view_image` не смог открыть SVG напрямую. Для визуальной проверки вектор нужно отрендерить во временный PNG через headless browser.
- При формировании prompt для fresh Architect worker неэкранированные backticks внутри JavaScript template literal вызвали локальный SyntaxError; перед повторным spawn нужно избегать inline backticks или экранировать их.
- Одноразовая локальная проверка очереди сравнила `wave` с суффиксом `-Wn` вместо нормализованного `Wn`; это была ошибка проверяющего скрипта, не ошибка task records.
