# Papercuts

- Local `ajv` could not compile the task schema because the installed runtime lacks the JSON Schema 2020-12 meta-schema (`no schema with key or ref "https://json-schema.org/draft/2020-12/schema"`). Continued with direct structural/index/DAG checks and the repository's `mb-lint` validation.
- One read-only diagnostic shell command ended early because of an unmatched quote in a `stat` path containing spaces. No project or reviewed artifact was changed; the command was retried with simpler quoting.
- A read-only `rg` command treated the literal SvelteKit route segment `[centerId]` as a shell glob and reported a missing path. The search was rerun against explicit quoted paths; no project artifact was changed.
- One multi-file `apply_patch` hunk placed the next task's expected line under the preceding file context and failed verification atomically. No file changed; the patch was split into correctly scoped hunks.
- A shell brace expansion intended to pair task IDs with waves generated a Cartesian product and noisy missing-file diagnostics. Coupled task filenames should be passed as exact paths.
- A supplemental queue validator encoded retained TASK-079/080 as `T2` although their records are `T3`; `mb-lint` had already passed, and the validator expectation was corrected before rerun.
- The same supplemental validator initially allowed only the Foundation external dependency and rejected legitimate retained FT-001 dependencies; external task records were then resolved and checked by status instead.
- A coupled three-card move patch used stale dependency formatting for TASK-092 and failed atomically; downstream card moves were retried as exact per-file patches.
