# Papercuts

- A validation command contained Markdown backticks inside a shell argument,
  so Bash attempted command substitution (`blocked` and `1`). The validation
  itself did not mutate project files; subsequent checks use quoting that
  prevents shell interpolation.

- The system Ajv package rejected the task schema's draft 2020-12 meta-schema
  because it only supports an older draft; project-native `node scripts/mb-lint.mjs`
  still passed, and the schema/index checks were rerouted to non-mutating
  structural validation.

- The first focused GREEN run exposed a test-fixture mistake: an empty override
  inherited the authorized default session, and an `admin-other` request used
  its own center. The fixture was corrected to pass an explicit undefined
  session and a genuinely cross-center request; no production behavior was
  changed by the failed assertion.

- The first two adversarial disposable-probe invocations failed before
  application execution because stdin was parsed as JavaScript while the
  one-off script still contained TypeScript syntax; the corrected probe passed
  and no project source or runtime state was changed.

- A combined Lesson Context boundary scan included test fixtures, so its
  intentional `homeworkId` setup triggered the production-bypass guard and
  short-circuited the native gates. The production-only scan passed; no source
  or runtime state was changed by the false-positive check.
