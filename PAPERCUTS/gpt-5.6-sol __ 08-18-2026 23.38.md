# Papercuts

- Один `functions.exec` вызов завершился синтаксической ошибкой из-за пропущенной запятой в объекте параметров `exec_command`; повторный вызов нужно было сформировать заново.
- Системный `ajv` не содержит meta-schema draft 2020-12, поэтому прямой запуск валидации task schema завершился ошибкой; проверку пришлось повторить с удалением только `$schema` из in-memory копии.
