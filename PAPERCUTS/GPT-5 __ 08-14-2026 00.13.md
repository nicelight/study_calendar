# Papercuts

- The supported `npm run bootstrap:admin` command emits Node's
  `ExperimentalWarning` for the project-owned `--loader` before the interactive
  prompts. The command still succeeds, but the warning makes the operational
  output look less settled than the documented bootstrap path.
- A validation search embedded Markdown backticks in a double-quoted shell
  pattern, so Bash attempted an unintended command substitution and printed a
  harmless `command not found`. The validation was rerun with literal-safe
  patterns; no project file or external state was affected.
