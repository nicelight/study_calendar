# Papercuts

- `git diff --check` не может служить чистым session-local gate: существующее пользовательское изменение `AGENTS.md` уже содержит дополнительную пустую строку в EOF (`AGENTS.md:226`), не относящуюся к review FT-007. Проверка review-артефактов выполняется отдельно, без изменения пользовательского файла.

- `/feature-doctor FT-007` обязан зафиксировать unresolved operator decision через `clarification_status: blocked`, сохранить существующие task artifacts и менять только feature/clarification protocol, но текущий `mb-lint` после этого безусловно отклоняет все уже indexed FT-007 cards как сгенерированные из blocked feature. В рамках skill scope queue не изменяется; локальная metadata/AC validation остаётся доступной, а полный lint ожидаемо блокирован до принятого ответа и reconciliation.

- Наивная локальная проверка Markdown anchors по полному slug заголовка ошибочно считает canonical feature locator вида `#FT-007-AC-001` неразрешимым, когда реальный heading продолжает ID человекочитаемым названием. Для task validation нужен prefix-match по нормализованному AC ID либо project-native resolver.
