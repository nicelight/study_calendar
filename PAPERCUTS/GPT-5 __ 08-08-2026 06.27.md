# Papercuts

- `git status --short` завершился ошибкой `not a git repository`: рабочая директория содержит Memory Bank, но не инициализирована как Git repository. Перед Git-диагностикой нужна короткая проверка наличия `.git`.
- Две попытки точечной замены через `apply_patch` не нашли строку, потому что исходная опечатка была неточно скопирована в patch; перед заменой нужно брать exact line из нумерованного вывода.
