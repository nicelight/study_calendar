# Invariants

## MUST
- Server-side операции MUST проверять роль, принадлежность к центру, классу и ученику.
- Персональные оценки, личные обсуждения и финансовые данные MUST быть доступны только разрешённому семейному контексту ученика, назначенному teacher и admin.
- Историческая цена начисления и денежная точность MUST сохраняться при последующих изменениях настроек и перерасчётах.
- Распределение платежей и перерасчёты MUST быть детерминированными и сохранять audit record для финансово значимых исправлений.

## NEVER
- Пользователь NEVER получает роль или доступ только за счёт входа через внешний provider и NEVER выбирает роль самостоятельно.
- Общий календарь NEVER раскрывает персональные оценки, личные обсуждения или финансовые данные другого ученика.
- Смысл состояния календаря NEVER передаётся только цветом.
- Визуальное размещение Payment marker NEVER изменяет фактический Payment, его allocation или баланс.
